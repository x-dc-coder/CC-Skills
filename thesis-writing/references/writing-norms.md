# 撰写规范摘要（无锡学院本科毕业论文）

本文件从《无锡学院本科毕业论文（设计）撰写规范及模板》中提取关键写作要求，
供 skill 生成 Markdown 内容时参考。格式相关的 Word 排版说明已略去。

## 正文结构

正文包括前言、本论、结论三个部分：
- **前言**：说明研究目的、意义、研究范围，国内外发展概况及存在问题
- **本论**：论文主体，包括总体方案论证、各部分设计实现、研究内容及成果阐述
- **结论**：集中反映研究成果，阐述创造性成果及意义，包括与已有结果比较和未来展望

## 字数要求

- 工科类：正文不少于 **15000 字**（含图表）
- 理科类：不少于 10000 字
- 文科类：不少于 8000 字

## 章节编号

理工科论文章节编号遵循《CY/T 35-2001 科技文献的章节编号方法》：
- 一级标题：1, 2, 3, ...
- 二级标题：1.1, 1.2, 2.1, ...
- 三级标题：1.1.1, 1.1.2, 2.1.1, ...
- 最多使用三级标题，不再使用四级以下

## 图片规范

- 每幅插图应有图序和图题，位于插图正下方
- 图序格式：图X-Y（X为章节号，Y为章内顺序号）
- 图序在图题左方不加标点，空一格接图题，图题末不加标点
- 全文插图按每章单独编序，编号必须连续，不得重复或跳缺
- 图应放在离正文首次出现处的近处，先文后图

## 表格规范

- 每个表格应有表序和表题，位于表格上方正中
- 表序格式：表X-Y（X为章节号，Y为章内顺序号）
- 表序后不加标点，空一格后写表题，表题末不加标点
- 编号必须连续，不得重复或跳缺
- 采用简明三线表格式
- 表格应放在离正文首次出现处的近处，先文后表

## 参考文献

- 格式遵循 GB/T 7714-2015《信息与文献 参考文献著录规则》
- 按正文中引用的先后顺序排列
- 引用标记使用方括号上标，如 [1]、[2]
- **重要：正文中提及他人研究成果、技术方法、数据集时，必须添加引用标记 [n]**
- 外文文献数量不少于总文献数量的 1/5
- 近五年文献数量不少于总文献数量的 1/3

### 正文引用示例

**正确示例：**
> 朱宏伟等人提出了基于RoBERTa-Seq2Seq模型的中文文本摘要方法[1]，通过改进MMR算法提升了摘要质量。

> Beltagy等人提出的Longformer模型专门用于处理长文档[13]，通过滑动窗口注意力机制扩展了上下文长度。

**引用位置规范：**
- 提及作者或研究团队后，紧跟引用标记
- 段落中涉及具体方法、模型、数据集时，应在首次出现时标注引用
- 一句话涉及多个引用时，格式如：[1][2][3] 或 [1-3]

### 常见参考文献格式

期刊论文 [J]：
```
[1] 作者. 题名[J]. 刊名, 年, 卷(期): 页码.
```

专著 [M]：
```
[2] 作者. 书名(版次)[M]. 出版地: 出版社, 年.
```

学位论文 [D]：
```
[3] 作者. 题名[D]. 地点: 学校, 年: 页码.
```

会议论文 [C]：
```
[4] 作者. 题名[C]//编者. 论文集名. 出版地: 出版社, 年: 页码.
```

电子文献 [EB/OL]：
```
[5] 作者. 题名[EB/OL]. (发布日期)[引用日期]. URL.
```

标准 [S]：
```
[6] 起草单位. 标准编号 标准名称[S]. 出版地: 出版社, 年.
```

## 摘要要求

- 中文摘要 150-350 字
- 包括研究目的与意义、研究内容与方法、研究结论
- 突出新论点、新见解或创造性成果
- 英文摘要内容与中文一致
- 关键词 3-5 个，用"；"分隔，按外延从大到小排列

## 致谢要求

- 对给予资助、指导、协助的单位和个人表示感谢
- 语言实事求是，切忌浮夸
