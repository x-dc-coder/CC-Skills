# 本科毕业论文写作规范（特有部分）

本文件仅包含本科毕设模式（Mode A）特有的写作规范。机械化 Markdown 规范（ATX 标题、图表语法、编号连续性等共享规则）见 `shared-markdown-norms.md`。

## 正文结构

正文包括前言、本论、结论三个部分：
- **前言**：说明研究目的、意义、研究范围，国内外发展概况及存在问题
- **本论**：论文主体，包括总体方案论证、各部分设计实现、研究内容及成果阐述
- **结论**：集中反映研究成果，阐述创造性成果及意义，包括与已有结果比较和未来展望

## 字数要求（本科毕设特有）

- 工科类：正文不少于 **15000 字**（含图表）
- 理科类：不少于 10000 字
- 文科类：不少于 8000 字

具体章节字数分配见 `undergrad-template.md`。

## 标题规范（特有约定）

理工科论文章节编号遵循《CY/T 35-2001 科技文献的章节编号方法》：
- 一级标题：1, 2, 3, ...
- 二级标题：1.1, 1.2, 2.1, ...
- 三级标题：1.1.1, 1.1.2, 2.1.1, ...
- 最多使用三级标题，不再使用四级以下

`check_markdown_spec.py`（默认 undergraduate 模式）支持的标题编号体系：
- **阿拉伯数字**（默认）：`# 1 绪论` → `## 1.1 背景` → `### 1.1.1 现状`
- 中文序号：`# 一、绪论` → `## （一）背景` → `### （一）现状`
- 章节式：`# 第一章 绪论` → `## 1.1 背景` → `### 1.1.1 现状`

## 参考文献规范（本科毕设特有）

- 格式**严格**遵循 GB/T 7714-2015《信息与文献 参考文献著录规则》（与期刊模式可选风格不同）
- 按正文中引用的先后顺序排列
- 引用标记使用方括号上标，如 [1]、[2]
- **重要：正文中提及他人研究成果、技术方法、数据集时，必须添加引用标记 [n]**
- 外文文献数量不少于总文献数量的 1/5
- 近五年文献数量不少于总文献数量的 1/3

### 正文引用示例

**正确示例：**
> 朱宏伟等人提出了基于RoBERTa-Seq2Seq模型的中文文本摘要方法[1]，通过改进MMR算法提升了摘要质量。

> Beltagy等人提出的Longformer模型专门用于处理长文档[13]，通过滑动窗口注意力机制扩展了上下文长度。

**引用位置规范：**
- 提及作者或研究团队后，紧跟引用标记
- 段落中涉及具体方法、模型、数据集时，应在首次出现时标注引用
- 一句话涉及多个引用时，格式如：[1][2][3] 或 [1-3]

### 常见参考文献格式

期刊论文 [J]：
```
[1] 作者. 题名[J]. 刊名, 年, 卷(期): 页码.
```

专著 [M]：
```
[2] 作者. 书名(版次)[M]. 出版地: 出版社, 年.
```

学位论文 [D]：
```
[3] 作者. 题名[D]. 地点: 学校, 年: 页码.
```

会议论文 [C]：
```
[4] 作者. 题名[C]//编者. 论文集名. 出版地: 出版社, 年: 页码.
```

电子文献 [EB/OL]：
```
[5] 作者. 题名[EB/OL]. (发布日期)[引用日期]. URL.
```

标准 [S]：
```
[6] 起草单位. 标准编号 标准名称[S]. 出版地: 出版社, 年.
```

## 摘要要求（本科毕设特有）

- 中文摘要 150-350 字
- 包括研究目的与意义、研究内容与方法、研究结论
- 突出新论点、新见解或创造性成果
- 英文摘要内容与中文一致
- 关键词 3-5 个，用"；"分隔，按外延从大到小排列
