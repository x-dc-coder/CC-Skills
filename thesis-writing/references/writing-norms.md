# Markdown 撰写规范摘要（理工科本科毕业论文）

本文件供 skill 生成 Markdown 内容时参考，仅描述 Markdown 源文件的撰写规范。

## 正文结构

正文包括前言、本论、结论三个部分：
- **前言**：说明研究目的、意义、研究范围，国内外发展概况及存在问题
- **本论**：论文主体，包括总体方案论证、各部分设计实现、研究内容及成果阐述
- **结论**：集中反映研究成果，阐述创造性成果及意义，包括与已有结果比较和未来展望

## 字数要求

- 工科类：正文不少于 **15000 字**（含图表）
- 理科类：不少于 10000 字
- 文科类：不少于 8000 字

## 标题规范

### 章节编号

理工科论文章节编号遵循《CY/T 35-2001 科技文献的章节编号方法》：
- 一级标题：1, 2, 3, ...
- 二级标题：1.1, 1.2, 2.1, ...
- 三级标题：1.1.1, 1.1.2, 2.1.1, ...
- 最多使用三级标题，不再使用四级以下

### Markdown 标题语法要求

- 必须使用 ATX 标题风格（`#` / `##` / `###`），禁止使用 Setext 风格（`===` 或 `---`）
- **一级标题** `#`：用于主章节和特殊标题
  - 章节：`# 1 绪论`、`# 2 需求分析`
  - 特殊标题：`# 摘要`、`# Abstract`、`# 参考文献`、`# 致谢`
- **二级标题** `##`：格式固定为 `数字.数字 标题`
  - 示例：`## 1.1 研究背景`、`## 2.1 用户需求`
- **三级标题** `###`：格式固定为 `数字.数字.数字 标题`
  - 示例：`### 1.1.1 国内现状`、`### 2.1.1 功能需求`
- 标题层级必须连续，禁止跳级（如 `#` 后不能直接接 `###`）
- 编号必须前后一致：二级标题的首数字必须匹配当前一级标题的章节号；三级标题的前两位数字必须匹配当前二级标题编号
- **禁止**在 Markdown 正文中使用一级标题书写论文题目

## 图片规范

- **必须使用 Markdown 图片语法**：`![图X-X 标题](./path/to/image.png)`
- 图片标题格式：`图X-X 标题`（如"图3-1 系统功能结构图"）
- **禁止在图片下方重复添加标题文字**（如 `**图3-1 系统功能结构图**`），标题应仅在图片的 `alt` 属性中体现
- 禁止使用 HTML `<img>` 标签
- 图序格式：图X-Y（X为章节号，Y为章内顺序号）
- 全文插图按每章单独编序，编号必须连续，不得重复或跳缺
- 图应放在离正文首次出现处的近处，先文后图

## 数学公式规范

- 行内公式使用 `$...$` 语法，如 `$E=mc^2$`
- 独立公式使用 `$$...$$` 语法
- 公式编号格式：`(X-Y)`，X 为章节号，Y 为章内顺序号
- 编号应置于公式右侧，与公式同一行或紧邻公式下一行
- 全文公式按每章单独编序，编号必须连续，不得重复或跳缺
- **禁止将公式以图片形式插入**（如公式截图），必须使用 LaTeX 数学语法书写

## 表格规范

- 使用标准 Markdown 表格语法
- 表格前必须有规范表题：`表X-X 标题`
- 表题与表格之间不要有空行
- 表序格式：表X-Y（X为章节号，Y为章内顺序号）
- 编号必须连续，不得重复或跳缺
- 表格应放在离正文首次出现处的近处，先文后表

## 参考文献

- 格式遵循 GB/T 7714-2015《信息与文献 参考文献著录规则》
- 按正文中引用的先后顺序排列
- 引用标记使用方括号上标，如 [1]、[2]
- **重要：正文中提及他人研究成果、技术方法、数据集时，必须添加引用标记 [n]**
- 外文文献数量不少于总文献数量的 1/5
- 近五年文献数量不少于总文献数量的 1/3

### 正文引用示例

**正确示例：**
> 朱宏伟等人提出了基于RoBERTa-Seq2Seq模型的中文文本摘要方法[1]，通过改进MMR算法提升了摘要质量。

> Beltagy等人提出的Longformer模型专门用于处理长文档[13]，通过滑动窗口注意力机制扩展了上下文长度。

**引用位置规范：**
- 提及作者或研究团队后，紧跟引用标记
- 段落中涉及具体方法、模型、数据集时，应在首次出现时标注引用
- 一句话涉及多个引用时，格式如：[1][2][3] 或 [1-3]

### 常见参考文献格式

期刊论文 [J]：
```
[1] 作者. 题名[J]. 刊名, 年, 卷(期): 页码.
```

专著 [M]：
```
[2] 作者. 书名(版次)[M]. 出版地: 出版社, 年.
```

学位论文 [D]：
```
[3] 作者. 题名[D]. 地点: 学校, 年: 页码.
```

会议论文 [C]：
```
[4] 作者. 题名[C]//编者. 论文集名. 出版地: 出版社, 年: 页码.
```

电子文献 [EB/OL]：
```
[5] 作者. 题名[EB/OL]. (发布日期)[引用日期]. URL.
```

标准 [S]：
```
[6] 起草单位. 标准编号 标准名称[S]. 出版地: 出版社, 年.
```

## 摘要要求

- 中文摘要 150-350 字
- 包括研究目的与意义、研究内容与方法、研究结论
- 突出新论点、新见解或创造性成果
- 英文摘要内容与中文一致
- 关键词 3-5 个，用"；"分隔，按外延从大到小排列

## 空格规范

- **正文中，中文字符与英文字母/数字之间不得有空格**
- 正确示例：`基于SpringBoot框架`、`MySQL 8.0数据库`、`Vue.js前端`、`借助RESTful API来进行通信`
- 错误示例：`基于 SpringBoot 框架`、`MySQL 8.0 数据库`、`Vue.js 前端`、`借助 RESTful API 来进行通信`
- 英文单词**内部**空格保留（如 `Spring Boot`、`RESTful API`、`Vue Router`）
- 行内代码、URL、参考文献编号、图片占位符不受此限制
