## 一、完整数据流动路径

原始输入RGB图像 → 第1组卷积+ReLU激活 → 第1组最大池化下采样 → 第2组卷积+ReLU激活 → 第2组最大池化下采样 → 第3组卷积+ReLU激活 → 扁平化+随机失活正则化 → 512维全连接隐藏层 → 10分类Softmax概率输出。

## 三、核心组件及其作用

1. **Conv2D + ReLU 卷积块**: 特征提取的核心。浅层卷积提取边缘、纹理等底层视觉特征，深层卷积提取物体部件、全局语义等高层特征；ReLU 激活引入非线性变换，大幅提升模型的特征拟合能力。

2. **MaxPool 最大池化块**: 对特征图做下采样，成倍降低空间维度，减少后续计算量和参数量。同时过滤冗余信息、保留最显著的强特征，提升平移不变性，一定程度缓解过拟合。

3. **Dropout 正则化组件**: 训练阶段随机关停部分神经元，打破神经元之间的共适应依赖关系，降低模型对训练集局部噪声的过拟合风险，提升泛化能力。

4. **Flatten 扁平化组件**: 完成维度变换，将卷积输出的四维空间特征序列转为一维向量，作为卷积特征提取部分和后续全连接分类头的衔接层。

5. **全连接 FC 隐藏层**: 对前面提取的多维度局部特征做全局整合，映射得到维度更紧凑的全局图像特征向量。

6. **Softmax 输出层**: 将最终的隐特征映射为符合概率定义的 10 分类输出，完成多分类任务的结果输出。

## 五、架构总结

该模型是一个经典的 **10 分类 CNN 图像分类器**，采用三层卷积 + 两层池化的特征提取结构，配合 512 维全连接隐藏层和 Softmax 分类头：

- **输入**: 224×224 RGB 图像
- **特征提取**: 3 组 Conv+ReLU（64→128→256 通道），中间穿插 2 次 MaxPool 下采样
- **最终特征图尺寸**: 256 通道 × 28×28
- **分类头**: Flatten → FC(200704→512) → Dropout → FC(512→10) → Softmax
- **输出**: 10 个类别的概率分布

模型参数量主要集中在第一层全连接层（200704 × 512 ≈ 1.03 亿参数），可通过在 Flatten 前增加全局平均池化（Global Average Pooling）来大幅减少参数量。
