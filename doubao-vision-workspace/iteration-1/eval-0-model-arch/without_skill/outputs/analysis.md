## 模型结构总结

- **网络类型**: VGG 风格 CNN 图像分类器
- **输入**: 224x224 RGB 三通道图像
- **特征提取**: 3 个卷积块（通道数 64 -> 128 -> 256），每个包含 Conv + ReLU + MaxPool
- **正则化**: 两次 Dropout(0.5)，分别位于 Flatten 后和 FC 后
- **分类头**: FC(200704 -> 512) + ReLU + FC(512 -> 10) + Softmax
- **输出**: 10 个类别的概率分布
- **参数量级**: Flatten 层 200704 维向量是参数主要来源，FC 512 层参数量约 200704*512 + 512 ≈ 1.03 亿
